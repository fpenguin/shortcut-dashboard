# Starter Pack Notices

Shortcut Dashboard starter packs are optional JSON files assembled from public shortcut references. They are practical keyboard maps, not official vendor documentation. They are designed to help users seed a personal dashboard quickly, then edit, delete, favorite, merge, and back up the commands that matter to their own workflow.

Verify important shortcuts inside the original app, especially if you use custom keymaps, a non-US keyboard layout, or an app version whose shortcuts differ from the cited source.

## Curated Public Documentation

Several starter packs were curated from public support pages, product manuals, and keyboard-shortcut reference pages published by app developers or other public shortcut references. The packs contain factual shortcut/action pairs only; no vendor artwork, screenshots, prose, long explanations, or branded assets are copied into the JSON.

Each starter pack records its source URL in `starterPack.source` and stores a short source note in each shortcut entry.

## Gaming References

Gaming starter packs are curated from official help pages where available and stable public community references when official shortcut tables are limited. They contain shortcut facts and source URLs only; user-uploaded or paywalled documents are avoided for distribution. The packs focus on default keyboard controls that can be represented on Shortcut Dashboard's visual keyboard, so mouse-only actions, numpad-only bindings, and highly situational controls may be intentionally omitted.
